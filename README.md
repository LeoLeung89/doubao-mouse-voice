# 鼠标长按豆包语音 macOS 版

这是 **macOS 专用**菜单栏工具：监听鼠标左键长按，模拟长按 Option，调用已安装的豆包输入法语音输入。Windows 版未开发、未测试，本项目不能直接在 Windows 上使用。

> 已在一台 Mac 上确认：设置为左 Option 后，鼠标长按可以唤起豆包语音。不同机型、macOS 和豆包输入法版本的兼容性尚未全面测试；下载包尚未完成独立安装测试。

## 下载软件

[下载 macOS Apple Silicon 版本](https://github.com/LeoLeung89/doubao-mouse-voice/releases/tag/v0.1.0-beta.1)。压缩包仅适用于 Apple 芯片 Mac；Intel Mac 未验证。

## 工作方式

- 左键按住 0.6 秒后模拟按住 Option，松开左键后释放 Option。豆包自身识别长按还可能需要额外时间。
- 默认模拟左 Option，可在菜单栏切换右 Option。
- 开始触发前移动超过 10 点则取消；原鼠标事件仍会送给当前应用，长按可能同时触发原应用的操作。
- 需要已安装并启用豆包输入法，且豆包已设置为长按对应的 Option 开启语音。

## 构建和运行

需要 macOS、Xcode 命令行工具（含 Swift 编译器）。下载源码后在项目目录执行：

```bash
bash build.sh
open '鼠标长按豆包语音.app'
```

本地构建使用临时自签名，不是 Apple 开发者签名或公证版本；其他 Mac 的安全设置可能阻止直接打开。程序不会自动申请麦克风权限，录音和识别由豆包输入法负责。

首次运行后，在“系统设置 → 隐私与安全性”允许本工具的“输入监控”和“设备控制和数据访问”（旧版 macOS 可能称“辅助功能”）；还需允许豆包输入法访问麦克风。授权后退出工具并重新打开。菜单栏可以暂停、切换 Option 和退出。若需开机自动启动，可在“系统设置 → 通用 → 登录项与扩展”中将本工具加入“登录时打开”。程序也会尝试使用 macOS 的登录项接口注册，实际状态以系统设置为准。

## 隐私与限制

本工具只使用 macOS 事件接口，不录音、不传输数据；使用输入监控和辅助功能权限的原因分别是监听鼠标和模拟按键。豆包的语音处理和隐私政策由豆包提供。

- 全局鼠标长按可能与选字、拖拽、长按菜单冲突。
- 用户反馈现有版本在一台 Mac 上语音联动成功；不同 macOS、输入法版本和键盘布局尚未进行兼容性测试。
- 松开鼠标结束的效果取决于豆包输入法的快捷键行为。
- 系统暂停监听或工具退出时会尝试释放模拟按键；异常终止时的行为未验证。
